# Evaluation Scripts

Scripts for evaluating translation quality and comparing service outputs.

## Scripts
- **evaluate_confidence.py** - Frequency-based agreement scoring across services
- **evaluate_github_alignment.py** - Alignment with GitHub language data
- **evaluate_meta_judge.py** - Meta-judge LLM evaluation
- **evalute_llm_judge.py** - LLM-based translation quality judgment

Each script is standalone and can be run independently.
